# Fórum Brasil de Turismo Cultural — case study

Apresentação técnica de um sistema web desenvolvido para apoiar a organização e a gestão do Fórum Brasil de Turismo Cultural.

> Este repositório é uma apresentação pública do projeto. Ele não contém o código proprietário do cliente, credenciais, dados reais de usuários, dumps de banco de dados ou configurações privadas.

## Visão geral

O sistema reúne uma experiência pública para divulgação do evento e recursos administrativos para apoiar programação, inscrições, credenciamento, participantes, certificados, comunicação e análise de impacto.

## Tecnologias

- Laravel e PHP
- Filament
- SQL e modelagem relacional
- Blade, JavaScript, HTML e CSS
- Vite e npm

## Meu trabalho no projeto

Atuei no desenvolvimento e na evolução de funcionalidades full stack, incluindo interfaces públicas e administrativas, fluxos de inscrição, regras de negócio, integração com banco de dados, validações, permissões, responsividade, acessibilidade e refinamentos de experiência.

## Segurança e privacidade

Foram deliberadamente excluídos código-fonte proprietário, arquivos .env, chaves, tokens, senhas, dados reais, exportações de banco, logs, scripts internos de diagnóstico e informações confidenciais do cliente.

A publicação deste case study deve respeitar as autorizações e as regras de confidencialidade do cliente.
