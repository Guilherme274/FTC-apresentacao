# Fórum Brasil de Turismo Cultural — case study

Apresentação técnica de um sistema web desenvolvido para apoiar a organização e a gestão do Fórum Brasil de Turismo Cultural.

> Este repositório é uma apresentação pública do projeto. Ele não contém o código proprietário do cliente, credenciais, dados reais de usuários, dumps de banco de dados ou configurações privadas.

## Visão geral

O sistema reúne uma experiência pública de divulgação do evento e recursos administrativos para apoiar atividades como:

- organização da programação;
- inscrições e gerenciamento de participantes;
- credenciamento e check-in com QR Code;
- controle de vagas e lista de espera;
- notícias, conteúdos e materiais do evento;
- gerenciamento de equipes e permissões;
- emissão e consulta de certificados;
- painel administrativo para operação do evento.

## Tecnologias

- Laravel e PHP;
- Filament;
- SQL e modelagem relacional;
- Blade;
- JavaScript;
- HTML e CSS;
- Vite e npm.

## Meu trabalho no projeto

Atuei no desenvolvimento e na evolução de funcionalidades full stack, incluindo:

- construção de interfaces públicas e administrativas;
- criação e manutenção de fluxos de inscrição;
- implementação de regras de negócio;
- integração entre frontend, backend e banco de dados;
- validação de formulários;
- permissões e controle de acesso;
- melhorias de acessibilidade e responsividade;
- correção de erros e refinamentos de experiência.

## Demonstração

- Site público: https://forumbrasilturismocultural.tech/
- Painel administrativo: https://forumbrasilturismocultural.tech/admin

O acesso ao painel é restrito e não há credenciais neste repositório.

## Segurança e privacidade

Para esta apresentação, foram deliberadamente excluídos:

- código-fonte proprietário;
- arquivos `.env`;
- chaves, tokens e senhas;
- dados reais de participantes;
- exportações de banco;
- logs;
- scripts internos de diagnóstico;
- informações confidenciais do cliente.

## Aprendizados

Este projeto me permitiu praticar desenvolvimento de aplicações reais com Laravel, Filament e SQL, além de trabalhar com requisitos, manutenção, correção de problemas e evolução contínua de um sistema utilizado em um contexto profissional.

## Observação

A publicação deste case study deve respeitar as autorizações e as regras de confidencialidade do cliente.
